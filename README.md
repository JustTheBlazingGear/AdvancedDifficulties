# Better Difficulties

![Icon](assets/icon.png)

A simple Mindustry mod that increases the tier of all enemy units by one.

Adds:
- All Serpulo and Erekir units increase in tier by one when spawned from waves (daggers turn into maces, flares into horizons, etc.).
- If it's a T5 or a modded unit, give overclock status (doesn't replace existing statuses like guardian).
- Stacks with vanilla V8 difficulty system.

That's it for now, but would be cool to rename this little project into Better Difficulties and add many, many small and quirky modifiers.
